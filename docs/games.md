# Games and what they need

What a counter can add for each game, beyond what the cards and tokens on the
table already do. "Unsure" marks rules that need checking before building.

## Counter types this implies

| Type | What it is | Games | Status |
|---|---|---|---|
| Life / score | One number per player, up or down, win/lose threshold | Magic, Lorcana, FaB, SWU | Done |
| Typed score | Each point tagged with how it was earned, in order | Riftbound (Conquer / Hold) | Done |
| Shared gauge | One marker that moves between the two players | Digimon (memory) | Idea |
| Amount entry | Type an amount (e.g. −1800) instead of tapping | Yu-Gi-Oh! (8000 LP) | Idea |
| Secondary counters | Extra per-player counters next to life | Magic (poison, commander damage, energy), others | Idea |
| Coin / dice | Quick random results | Pokémon (coin flips), casual play | Done |
| Turn / clock | Whose turn, turn count, per-player chess clock | Any; events | Idea |

## By game

| Game | Fit | Notes |
|---|---|---|
| **Riftbound** | Strong | Points to 8 by Conquer or Hold; the order matters. 2v2 team score (target unconfirmed). |
| **Magic** | Strong | Life 20 / 40; poison (10); commander damage from each opponent (21); energy, experience. Up to 4 players in Commander. |
| **Yu-Gi-Oh!** | Strong | 8000 LP with large, arbitrary changes. LP calculators are already an established accessory, so this is a real market. Needs amount entry and halving. |
| **Digimon** | Strong | Memory gauge from 10 on one side to 10 on the other; one marker crosses between players and decides whose turn it is. A shared-gauge screen is a natural fit. Security is physical cards. |
| **Lorcana** | Good | Lore to 20. |
| **Flesh and Blood** | Good | Life (hero-dependent, e.g. 20 / 40). |
| **Star Wars: Unlimited** | Good | Damage on each player's base, up to the base's HP; initiative. |
| **Pokémon** | Light | 6 prize cards are physical (a KO takes 1, 2 or 3 depending on the Pokémon), so prize tracking is rarely needed. Coin flips are frequent, so the coin is useful. Damage on the Active Pokémon is possible but usually tracked with counters on the card. |
| **One Piece** | Light | Life cards and DON!! are physical. Little to count beyond a turn/first-player helper. |
| **Gundam Card Game** | Unsure | Need to learn the rules first. |
| **Jurassic Park TCG** | Unsure | Need to learn the rules first. |
| **Cookie Run: Braverse** | Unsure | Need to learn the rules first. |

Games whose life or points are physical cards (One Piece, Pokémon) benefit
least; games with a running number (Magic, Yu-Gi-Oh!, Lorcana, Riftbound) or
a shared marker (Digimon) benefit most.
